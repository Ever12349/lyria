Lyria · Window Chrome（原生标题栏约定）

  1. NSWindow.styleMask 含 .titled + .fullSizeContentView
  2. titlebarAppearsTransparent = true、titleVisibility = .hidden — 无自定义黑色顶栏条
  3. 红绿灯由系统绘制，视觉上落在左侧栏顶部内部（侧栏玻璃通顶）
  4. 拖动 / 双击放大还原走系统 NSThemeFrame；穿透区收窄为系统标题栏拖动带（hitTest → nil），勿整顶约 52pt 一律穿透；不自定义 performZoom
  5. 侧栏相对窗口四边留出约 12px，圆角约 18px；底栏（Transport）只在详情列下方，不延伸到侧栏下。设置下不放拖宽示意点
  6. 详情列顶部是导航标题，与搜索、列表、底栏左右对齐。能返回时，后退图标在标题左侧并与文字对齐
  7. 侧栏可拖宽 168–320（默认 ~228）
  8. Deep Space：左右同色 #0a0b1a 系，禁用吸壁纸 vibrancy
  9. Accent 渐变 #9b87f5 → #7c3aed；圆角 16–24
