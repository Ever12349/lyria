Lyria · Window Chrome（原生标题栏约定）

  1. NSWindow.styleMask 含 .titled + .fullSizeContentView
  2. titlebarAppearsTransparent = true、titleVisibility = .hidden — 无自定义黑色顶栏条
  3. 红绿灯由系统绘制，视觉上落在左侧栏顶部内部（侧栏玻璃通顶）
  4. 拖动 / 双击放大还原走系统 NSThemeFrame；SwiftUI 顶约 52pt hitTest → nil 穿透，不自定义 performZoom
  5. 侧栏通底全高；底栏（Transport）只在详情列下方，不延伸到侧栏下
  6. 侧栏可拖宽 168–320（默认 ~228）
  7. Deep Space：左右同色 #0a0b1a 系，禁用吸壁纸 vibrancy
  8. Accent 渐变 #9b87f5 → #7c3aed；圆角 16–24
